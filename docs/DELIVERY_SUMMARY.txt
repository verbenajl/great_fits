================================================================================
                      KEY FEATURES EXPLAINED
================================================================================

1. SCIENCE LINE DETECTION
   ─────────────────────
   Uses OpenCV algorithm to automatically detect emission/absorption lines
   
   Algorithm:
   • Gaussian blur (kernel_size, default 51)
   • Threshold at mean + cutoff_std×σ
   • Iterative refinement (typically 2-3 iterations)
   • Output: Boolean mask of line regions
   
   Parameters:
   • --line-kernel-size SIZE      (default: 51, must be odd)
   • --line-cutoff-std SIGMA      (default: 2.0)
   • --smoothing-kernel SIZE      (optional refinement kernel)
   • --no-line-detection          (disable if needed)

2. FALLBACK TO CONFIG WINDOW
   ──────────────────────────
   If line detection fails or finds nothing, uses velocity window from config
   
   From config.toml:
   [reduction]
   window = [450, 500]    # km/s
   
   Or via command line:
   --config-window 450 500
   
   Automatically maps velocity to channel indices using VELOCITY_AXIS

3. COMPONENT SELECTION
   ───────────────────
   Two independent cutoffs control which components get subtracted:
   
   • Variance Cutoff: Only use components > X% variance
     --variance-cutoff 0.01  (e.g., 1%)
   
   • Noise Ratio Cutoff: Skip if noise_ratio > threshold
     --noise-ratio-cutoff 3.0
     
   Noise Ratio = std(spectrum) / std(fitted_component)
   High ratio = weak component relative to noise (skip it)

4. DIAGNOSTIC PLOTS
   ────────────────
   With --plot flag, generates per-scan/telescope PNG files:
   
   Panel 1: Mean Spectra (original red vs corrected green)
   Panel 2: Original 2D Spectra Array (heatmap)
   Panel 3: Corrected 2D Spectra Array (heatmap)
   Panel 4: Difference (original - corrected, shows removed components)
   
   File: output/pca_corrected/pca_correction_<mission>_<scan>_<telescope>.png

                         WORKFLOW EXAMPLE
================================================================================

Step 1: Decompose SKYCHOPDIFF (learn instrumental variations)
  $ pca_decompose --config config.toml --plot-components
  Output: output/pca_components/decomposition_2017-02-01_GR_F367_2017021_components.pkl

Step 2: Correct M51CENTER (remove instrumental variations from science data)
  $ pca_correct \
      --input /path/to/reduced_data.fits \
      --decomposition output/pca_components/decomposition_2017-02-01_GR_F367_2017021_components.pkl \
      --output /path/to/pca_corrected.fits \
      --object M51CENTER \
      --config-window 450 500 \
      --plot
  
  Output: /path/to/pca_corrected.fits
          output/pca_corrected/pca_correction_*.png

Step 3: Analyze Results
  - Check output FITS file
  - Review diagnostic plots
  - Compare before/after spectra
  - Adjust parameters if needed

================================================================================
                      CONFIGURATION INTEGRATION
================================================================================

The pca_correct command respects config.toml settings:

[reduction]
baseline = 3            # Baseline order for spectrum preparation
window = [450, 500]     # Fallback window for science lines (km/s)

[pca]
n_components = 5        # Number of components used
pca_source = "SKYCHOPDIFF"  # Source for decomposition

[output]
pcad_fits = "path/to/pca_corrected.fits"  # Output file

VELOCITY AXIS:
The FITS file contains VELOCITY_AXIS column (m/s):
- Automatically converted to km/s for processing
- Used for telluric masking in decomposition
- Used for science line detection in correction
- Used for velocity-axis plots
