✓ PARAMETER EXTRACTION
  Both extract from identical FITS sources:
  - VELOCITY column (reference velocity, m/s)
  - DELTAV column (velocity spacing, m/s)
  - CRPIX1 header (reference pixel, 1-indexed FITS)
  - SPECTRUM column (channel count)
  
  No discrepancies found

  Both correctly handle FITS 1-indexed reference pixel:
  - Read CRPIX1 from header (1-indexed)
  - Convert to 0-indexed for Python: (crpix1 - 1)
  - Maintain correct velocity mapping
