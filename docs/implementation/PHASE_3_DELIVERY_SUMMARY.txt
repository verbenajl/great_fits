## 🏗️ Architecture

### 6 Core Classes

1. **CorrectionConfig** (Dataclass)
   - Configuration for correction operations
   - Serialization support (to_dict, from_dict)

2. **SpectrumProjector**
   - Projects spectra onto PCA components
   - Methods: project_spectrum, project_multiple
   - Handles metadata and shape validation

3. **CorrectionCalculator**
   - **Core Engine**: Mean-centered least-squares algorithm
   - Computes optimal [n_comp, n_comp] correction matrix
   - SVD-based principal component alignment
   - Diagonal scaling by component means
   - Methods: calculate_correction, apply_correction

4. **ScienceDataLoader**
   - Loads science spectra from FITS files
   - Filters by source, applies quality checks
   - Returns matrices + metadata

5. **CorrectionResult** (Dataclass)
   - Complete results container with provenance
   - Methods: reconstruct_corrected_spectra, get_correction_strength, summary
   - Persistence: save/load via pickle

6. **correct_spectra()** Function
   - High-level orchestration
   - One-function complete workflow
   - Parameters: fits_directory, decomposition_file, config, mission, mission_id

### Data Flow
```
FITS Files
    ↓
Phase 1: Load & Process
    ↓
Reference Spectra → Phase 2: Decompose → Components + Mean
                       ↓
              Science Spectra
                       ↓
        Phase 3: Project & Correct
                       ↓
        Corrected Spectra (Output)
```

## 🔬 Algorithm: Mean-Centered Least-Squares

### The Challenge
- Reference spectra: n_ref samples
- Science spectra: n_science samples
- Can't do 1:1 mapping (different counts)

### The Solution
1. Center both coefficient matrices by their means
2. Compute SVD of their covariance matrices
3. Align principal directions via rotation matrix
4. Apply diagonal scaling by mean ratios
5. Combine: C = Scaling × Rotation

### Why This Works
- Handles variable spectrum counts gracefully
- Aligns the statistical distributions
- Numerically stable (SVD)
- Interpretable per-component scaling
- Robust to singular matrices (pseudoinverse)

## 🚀 Quick Start

### Minimal Example
```python
from oi_zeigt.pca_analysis import correct_spectra

result = correct_spectra(
    fits_directory="/data/fits",
    decomposition_file="phase2.pkl",
    config_file="config.toml",
    mission_file="mission.toml",
    mission_id="VLTI"
)

print(result.summary())
```

### Get Corrected Spectra
```python
corrected_spectra = result.reconstruct_corrected_spectra()
# Returns: [n_science, n_channels] array
```

### Get Statistics
```python
strength = result.get_correction_strength()
# Returns: dict with per-component and total strength
```

### Save Results
```python
result.save("correction_result.pkl")
loaded = CorrectionResult.load("correction_result.pkl")
```
